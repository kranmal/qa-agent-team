Try it for real

$ git clone https://github.com/kranmal/qa-agent-team.git && cd qa-agent-team && ./install.sh $ cd /path/to/your/project $ claude --agent qa-lead

Start it as the main agent: a sub-agent can't start other sub-agents, so only the lead can fan out the work. Outputs land in qa/.
